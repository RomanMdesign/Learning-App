# 📚 Interactive Academic Vocabulary Builder & Quiz App

Isang web application na ginawa gamit ang **HTML, CSS, at JavaScript** upang matulungan ang mga mag-aaral na mapalawak ang kanilang bokabularyo sa iba't ibang akademiko at bokasyonal na asignatura sa pamamagitan ng interactive flashcards at quiz mode.

---

## 🌟 Mga Tampok (Features)

* **6 na Akademikong Sektor:**
  * 🔬 Science
  * 📐 Mathematics
  * ✍️ Filipino
  * 📊 Research
  * 🎨 Humanities
  * 📈 Accountancy
* **Dynamic Theme:** Nagbabago ang kabuuang kulay at visual layout batay sa napiling sektor.
* **Bilinggwal (Tagalog / English):** May katumbas na Ingles at malinaw na depinisyon ang bawat salita upang madaling maunawaan.
* **Visual Category Badges:** Color-coded na marka batay sa uri ng salita (e.g., *Proseso, Konsepto, Elemento, Teorya, Pinansyal, Sukat*).
* **Interactive Quiz Mode:** May instant scoring at randomized choices para sa mas mabilis na pag-aaral.

---

## 🛠️ Mga Teknolohiyang Ginamit

* **HTML5** - Estruktura ng website
* **CSS3** - Disenyo at dynamic color variables
* **JavaScript (Vanilla JS)** - Lohika ng bokabularyo, pagpapalit ng tema, at quiz functionality
